Module 04  ·  Geometric attributes

Coherence is not one calculation

Module 03 got the analysis window aligned with the bed, so the traces inside it can finally be compared. This module is about what "compared" means. Several different attributes all get called coherence, they measure different properties, and on the same data they disagree — sometimes completely.

Step 1  ·  How similar are two traces?

Before any equation, decide what your eye says

Four cases. Look at each and decide, before reading any number, whether you would call the two traces similar. Case 3 is the interesting one: the shape is identical and only the size differs. Is that similar or not? Your answer decides which attribute you should be running.

What the two numbers disagree about—
Crosscorrelation is normalised by the energy of each trace separately, so it ignores a change of scale. Semblance is not, so it does not. Neither is right; they answer different questions. That distinction is the whole of this module.

Step 2  ·  From two traces to a window

The question becomes: are these one event?

Attributes are not computed on pairs of traces but on a window of several, aligned along the bed by the dip field from modules 01 to 03. The question the algorithm asks is whether the whole window can be described as one coherent seismic event. Two long-standing ways of answering it are below.

Step 3  ·  One matrix underneath all of it

The covariance matrix and its eigenvalues

Everything AASPI computes except the Sobel filter comes from a single object: a covariance matrix built from the window. Entry C(m,n) is trace m multiplied by trace n, summed down the window. A window of J traces gives a J-by-J matrix, and it is built from the analytic trace — the amplitude together with its Hilbert transform — which stabilises the result near amplitude zero crossings.

Its eigenvalues say how many independent patterns the window contains. If every trace is the same waveform, one pattern explains everything and there is a single large eigenvalue. If the traces are unrelated, the energy is spread across all of them.

Step 4  ·  One equation, three named attributes

The difference is a single vector

AASPI defines outer-product similarity as c = rᵀ C r / E, where E is the total energy in the window and r is a test vector. Changing r is what turns one equation into different published attributes.

  • Set r to a constant vector of J equal components and you get a semblance estimate of coherence.
  • Set r to the first eigenvector and you get eigenstructure coherence, which is the same as λ₁ divided by the sum of the eigenvalues.
  • Set r to the sample vector through the analysis point and you get the third option AASPI offers.

1 The test vector you chose one weight per trace

2 The whole family on this window same data, same window, same matrix

Energy-ratio coherence is the energy of the Karhunen–Loève filtered data over the total energy. Because the eigenvectors are orthonormal, keeping L components retains exactly the first L eigenvalues, so with L = 1 it is numerically identical to eigenstructure coherence. Raise L and everything starts to look coherent, because you are keeping more of the window as "signal".

Step 5  ·  Sobel: the one that is not a covariance

An image-processing edge detector, steered along dip

The Sobel filter comes from image processing rather than from seismic statistics. AASPI describes its version as the magnitude of the inline and crossline derivatives of amplitude along structural dip, normalised by the same derivatives taken on absolute values. It never builds a covariance matrix and it has no concept of a common waveform. It simply asks how fast amplitude is changing sideways, which makes it respond strongly to a change in size that the eigenvalue-based attributes ignore entirely.

Sign convention. As published, the equation gives a value near 0 where traces are identical and near 1 across an edge, so it is an edge response. The AASPI output volume is named sobel_filter_similarity and is used elsewhere in the software as a similarity where 1 means coherent, so the shipped attribute is presumably one minus this. Both are shown so nothing is hidden. This 2D page implements the inline term only; AASPI uses inline and crossline.

Step 6  ·  The same data, five problems, five attributes

Where the algorithms part company

One synthetic line, flat-lying so that steering is not a factor, divided into five zones. Each zone has a sharp vertical edge at its centre, and each edge is a different kind of problem. Every attribute is computed at every sample with the same window.

· All five attributes at each edge taller is more coherent, except Sobel, which is an edge response

Semblance, eigenstructure, energy ratio and variance all run 0 to 1 and share a grey scale, so they can be compared directly. The Sobel panel cannot: it is an edge response, high where the others are low, and it is plotted on its own scale. Putting a common colour bar on attributes that do not share a range or a sign is one of the easiest ways to mislead yourself.

Exercises

  1. Make the two attributes disagree completely. In step 2, set the amplitude change to 65% and leave the waveform change at zero. Then read semblance and eigenstructure in step 4. Eigenstructure and energy ratio read exactly 1.000 while semblance reads 0.896. Push the amplitude change to 80% and semblance falls to 0.818 while the other two do not move at all. This is not a bug in either. If every trace is the same waveform at a different size, the whole window is one pattern scaled trace by trace, so the covariance matrix has a single non-zero eigenvalue and the eigenvalue-based attributes correctly report one coherent event. Semblance compares each trace with the average trace, and a half-size trace is not the average trace. AASPI states this explicitly: energy ratio measures lateral changes in waveform but is independent of amplitude, while semblance is sensitive to both.
  2. Watch the eigenvalues collapse to one. With the amplitude change still at 65%, look at the eigenvalue panel in step 3. λ₁ holds essentially all the energy and λ₂ onwards are at the level of rounding error: the readout shows λ₁ holding 100.00% of the energy and λ₂ holding 0.00%. The matrix is rank one. That is the mathematical statement of "same waveform, different size", and it is why the ratio λ₁ / Σλ cannot see the amplitude change. Now add a waveform change and a second eigenvalue lifts off the floor immediately.
  3. Turn the gain up and down. First set the waveform change to about 40°, so that there is something for the variance to measure. Then move the overall amplitude slider from 0.2 to 3 and watch the three numbers underneath. Semblance holds at 0.9405 and normalised variance at 0.0590 through the whole sweep, because both are ratios of energies and the scale cancels exactly. The raw variance goes from 3.5 × 10⁻⁷ to 8.0 × 10⁻⁵, a factor of 225, which is 15 squared. That is why raw statistical variance is not usable as a seismic attribute and why packages displaying "variance" display a normalised form. It is also the reminder that a bright reflector and a dim one can be equally coherent.
  4. Raise L and watch coherence appear from nowhere. In step 4, set the noise in step 2 to about 40% and then move L from 1 to 3. Energy ratio climbs from 0.78 at L = 1 to 0.96 at L = 2 and 0.99 at L = 3, without the data changing at all. Keeping more principal components means calling more of the window "signal", so of course more of it looks coherent. AASPI notes that for small windows of 5 or 9 traces the first component usually represents more than 95% of the variability, and that L = 2 or 3 is intended for windows of 25 traces or more. Using a large L on a small window quietly erases the anomaly you were looking for.
  5. Find the case where they rank the opposite way round. In step 6, compare zone 2 with zone 5 across all five attributes. At the amplitude edge semblance reads 0.79 and energy ratio 1.00: semblance sees an edge, energy ratio sees nothing. At the fault semblance reads 0.29 and energy ratio 0.88: both see something, but semblance far more strongly. So the two attributes do not simply differ in sharpness, they order the two features differently. If you are mapping architectural elements inside a thin channel, where the waveform is constant and only amplitude changes, energy ratio will show you nothing and semblance will show you the edges — which is exactly the end member AASPI identifies.
  6. Check that low coherence is not the same as a fault. In step 6, look at the noise zone in each attribute. Every attribute goes dark in zone 4, and there is no fault there, no stratigraphic edge and no geology of any kind — only noise. Nothing in the number distinguishes it from zone 5. That distinction has to come from you, from the seismic itself, and from whether the anomaly is planar, laterally persistent and consistent between attributes.

The main points

  • Coherence names a family, not a formula. Semblance, eigenstructure, energy ratio, variance and Sobel all get called coherence and all measure something different.
  • Most of them are one equation with a different test vector. Outer-product similarity with a constant vector is semblance; with the first eigenvector it is eigenstructure.
  • The dividing line is amplitude. Eigenstructure and energy ratio are blind to a pure change of amplitude; semblance and Sobel are not. Which behaviour you want depends on what you are mapping.
  • A number without its algorithm is not interpretable. "Coherence is 0.8" says nothing until you know which one, over what window, with what L.
  • Low coherence means a local loss of waveform similarity, nothing more. Faults are one cause. Noise, acquisition footprint, processing artefacts, amplitude changes, tuning effects and a poor dip estimate all produce it too.
  • Do not share a colour bar between attributes that do not share a range or a sign. An edge response and a similarity are not the same quantity even when both happen to run 0 to 1.
Method, sources, and what has been simplified

Source. The definitions on this page are taken from AASPI, Geometric Attributes: Program similarity3d, Attribute-Assisted Seismic Processing and Interpretation, University of Oklahoma, 13 June 2022, and are cited by that document's equation numbers below. Nothing here has been substituted for something easier to implement.

Covariance matrix, equations 1a and 1b: built from 2K+1 sample vectors through the amplitude and a further 2K+1 through its Hilbert transform. The quadrature vectors occupy the same window, so they do not change vertical resolution, but they stabilise the estimate near amplitude zero crossings and suppress the artefact known as structural leakage. The optional per-sample taper of equation 1b and the sample-vector balancing option are not implemented here.

Semblance, equation 11: the energy of the average trace over the average of the energies of the individual traces. Outer-product similarity, equation 12: c = rᵀCr / E_tot, with the test vector of equation 13 giving semblance and r = v⁽¹⁾ giving eigenstructure. Eigenstructure coherence, equation 9, from Gersztenkorn and Marfurt (1999): λ₁ / Σλⱼ. Energy-ratio coherence, equation 10: E_coh / E_tot, with the two energies defined by equations 7 and 8.

One derivation is mine, not the document's. AASPI describes energy ratio as closely related to but slightly more general than eigenstructure. Because the eigenvectors are orthonormal, the energy retained by keeping the first L principal components is exactly the sum of the first L eigenvalues, so for an untapered, unbalanced window the two are numerically identical at L = 1. The extra generality is L > 1 and the tapered, balanced windows used for data-adaptive analysis. This page computes energy ratio that way; the equality is checked to nine decimal places.

Sobel-filter similarity, equation 15, with two departures stated in step 5. This is a 2D page, so only the inline derivative term exists where AASPI uses inline and crossline. And as published the equation returns a value near zero for identical traces, making it an edge response rather than a similarity, while the output volume of the same name is treated elsewhere in AASPI as a similarity where 1 means coherent. The likely resolution is that the shipped attribute is one minus this quantity, but the documentation does not say so, and rather than guess, both are displayed.

Variance is not an AASPI attribute. Program similarity3d does not output one. AASPI lists variance among the names the coherence family has acquired, some algorithmic and some simply renaming. The normalised form shown here follows the generic usage described in the SEG Wiki entry on coherence, where variance is mathematically close to 1 − semblance. The raw statistical variance is shown alongside it only to demonstrate why the normalised form is the one that gets used.

Other simplifications. The line in step 6 is flat, so dip steering is not a factor and the module can concentrate on the comparison; module 03 covers what happens otherwise. The multispectral forms, the amplitude gradients, the Laplacian filters, the data-adaptive windows and the structure-oriented filtering that similarity3d also provides are all left out.
